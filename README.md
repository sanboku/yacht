# ヨット

サイコロを5つ振って役を作る、ダイスゲーム「ヨット」のウェブアプリです。

https://sanboku.github.io/yacht/

## 遊び方

### 1台で遊ぶ
1台のスマホを順番に回して遊びます（1〜4人）。

### オンラインで遊ぶ
それぞれのスマホで、離れた人とも遊べます（2〜4人）。

1. 1人が「部屋を作る」を押し、表示された「招待リンクを送る」で LINE などに送ります。
2. 他の人はリンクを開いて「部屋に入る」（または部屋コードを入力）。
3. 全員そろったら、部屋を作った人（ホスト）が「ゲーム開始」。

- 接続が切れた人は、招待リンクを開き直すと同じ席に戻れます。
- 切断中の人の番は、ホストが代わりに進められます。
- ホストがページを閉じるとゲームは終了します。

### ルール
- 全12ラウンド。1ターンに最大3回までサイコロを振れます。
- サイコロをタップすると「キープ」され、次に振るときに固定されます。
- 振ったあと、得点表の空いている役を1つ選んで記入します（0点でも記入が必要）。
- 合計点が一番高い人の勝ちです。

## 役と得点

| 役 | 条件 | 得点 |
| --- | --- | --- |
| エース〜シックス | — | 該当する目の合計 |
| ボーナス | エース〜シックスの合計が63点以上 | 35点 |
| チョイス | なし | 全ての目の合計 |
| フォーダイス | 同じ目が4つ以上 | 全ての目の合計 |
| フルハウス | 同じ目3つ＋同じ目2つ | 全ての目の合計 |
| S.ストレート | 4つの目が連続 | 15点 |
| B.ストレート | 5つの目が連続 | 30点 |
| ヨット | 5つ全て同じ目 | 50点 |

## 開発

`index.html` をブラウザで開くだけで動きます（ビルド・インストール不要）。

- `game.js` … ルールと得点計算（画面に依存しないロジック）
- `board.js` … ゲーム画面（得点表・サイコロ）の描画
- `online.js` … オンライン対戦の通信
- `main.js` … 画面遷移と、1台モード／オンラインモードの制御
- `style.css` … 見た目
- `vendor/peerjs.min.js` … [PeerJS](https://peerjs.com/) 1.5.4（MIT ライセンス）

オンライン対戦は WebRTC で端末同士を直接つなぎます。端末同士が出会うための仲介には PeerJS の無料公開サーバー（0.peerjs.com）を使っており、
ゲームの状態はホストの端末が持ちます。モバイル回線の種類によっては直接つながらない場合があります。

テストの実行（Node.js 18 以上）:

```sh
npm test
```
