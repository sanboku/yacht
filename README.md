# ヨット

サイコロを5つ振って役を作る、ダイスゲーム「ヨット」のウェブアプリです。
1〜4人で、1台の端末を回して遊べます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・インストール不要）。

- 全12ラウンド。1ターンに最大3回までサイコロを振れます。
- サイコロをクリックすると「キープ」され、次に振るときに固定されます。
- 振ったあと、得点表の空いている役を1つ選んで記入します（0点でも記入が必要）。
- 合計点が一番高い人の勝ちです。

## 役と得点

| 役 | 条件 | 得点 |
| --- | --- | --- |
| エース〜シックス | — | 該当する目の合計 |
| ボーナス | エース〜シックスの合計が63点以上 | 35点 |
| チョイス | なし | 全ての目の合計 |
| フォーダイス | 同じ目が4つ以上 | 全ての目の合計 |
| フルハウス | 同じ目3つ＋同じ目2つ | 全ての目の合計 |
| S.ストレート | 4つの目が連続 | 15点 |
| B.ストレート | 5つの目が連続 | 30点 |
| ヨット | 5つ全て同じ目 | 50点 |

## 開発

- `game.js` … ルールと得点計算（画面に依存しないロジック）
- `main.js` … 画面の描画と操作
- `style.css` … 見た目

テストの実行（Node.js 18 以上）:

```sh
npm test
```
